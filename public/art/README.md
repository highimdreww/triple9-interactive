# Approved artwork

Place approved artwork in subfolders named after the title ID. The exact proposed paths, source dimensions, safe areas, and size budgets live in src/content/titles.json. No images are required for v1: null sources render the live-type tonal treatment.

Do not rename a file without also updating its src field. plannedPath is a handoff instruction, not a request for the browser to load a missing file. See ART-DIRECTION.md at the repository root.
